# Amazon Price Comparison Site

A Next.js application that helps users find the best deals on Amazon products, compare prices, and track price history.

## 🚀 Features

- 🔍 Product Search with Auto-suggestions
- 📊 Price History Tracking
- 🏷️ Deal Alerts
- 🛍️ Category Browsing
- ⭐ Prime Deals Section
- 📱 Responsive Design
- 🎨 Beautiful UI with Tailwind CSS
